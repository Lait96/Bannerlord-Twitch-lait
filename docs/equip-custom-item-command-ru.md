# Экипировка особого предмета

{% include doc-toc.html %}

Команда позволяет зрителю просмотреть особые предметы своего усыновлённого героя и экипировать выбранный предмет во все подходящие слоты.

В примерах используется русский синоним `!Экипировать`, доступный по умолчанию. Стример может изменить имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

## Основные ограничения

Для использования команды зрителю нужен усыновлённый герой хотя бы с одним особым предметом.

Команда недоступна:

- во время миссии, в том числе сражения;
- пока герой находится в плену;
- если стример отключил действие в его настройках.

Если стример установил стоимость, у героя должно быть достаточно золота. Золото списывается перед попыткой экипировать предмет.

## Просмотр особых предметов

```text
!Экипировать
```

Команда без аргументов выводит пронумерованный список особых предметов героя. Для каждого предмета показываются название и тип.

Индексы начинаются с `1` и соответствуют текущему порядку предметов в списке. Используйте показанный индекс сразу после просмотра списка: при изменении содержимого хранилища порядок может измениться.

## Экипировка по индексу

```text
!Экипировать Индекс
```

Пример:

```text
!Экипировать 2
```

Команда выбирает второй особый предмет из списка героя.

Индекс должен быть целым числом от `1` до количества предметов. Символ `#` перед индексом не поддерживается.

## Экипировка по названию

```text
!Экипировать Название предмета
```

Пример:

```text
!Экипировать Закалённый меч
```

Название можно ввести целиком или частично. Поиск выполняется без учёта регистра по отображаемому названию предмета с его модификаторами. Если введённый текст подходит нескольким предметам, используется первое совпадение в списке.

У команды нет подкоманд или фиксированных текстовых режимов. Она принимает один необязательный аргумент:

| Аргумент | Назначение |
|---|---|
| `Индекс` или `Название предмета` | Выбор особого предмета; без аргумента выводится список |

## Как выбираются слоты

Выбранный предмет проверяется для каждого слота, предусмотренного классом героя. Команда экипирует его во все совместимые слоты, которые пусты или уже содержат предмет того же типа.

Сравнение характеристик не выполняется: команда следует явному выбору зрителя и может заменить более сильное снаряжение. Один особый предмет может быть установлен сразу в несколько подходящих слотов.

Если ни один слот не подходит, команда сообщит об ошибке. При настроенной стоимости золото к этому моменту уже будет списано, поскольку оплата выполняется до проверки слотов.

## Настройки стримера

### Включено

Определяет доступность самого действия. Когда настройка выключена, команда не экипирует предметы и сообщает, что действие отключено.

### Стоимость в золоте

Количество золота, которое списывается с героя за попытку экипировать особый предмет. Стандартное значение — `0`, поэтому по умолчанию команда бесплатна.

Стоимость не применяется к просмотру списка: запуск `!Экипировать` без аргументов золото не списывает.

Стример также может включить или отключить всю команду, изменить основное имя `equipcustom` и список синонимов, включая `Экипировать`, разрешить использование только модераторам, скрыть команду из справки и выбрать каналы для вывода ответа.

В стандартной конфигурации ответы отправляются в Twitch.
