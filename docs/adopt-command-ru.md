# Усыновление героя

{% include doc-toc.html %}

Команда усыновления закрепляет за зрителем героя Bannerlord. Имя выбранного или созданного персонажа меняется на имя зрителя, после чего этот герой используется другими командами мода.

В примерах используется русский синоним `!Усыновить`, доступный по умолчанию. Стример может изменить имя команды, её синонимы и режим выбора героя. В этом случае используйте вариант и формат, указанные в списке команд канала.

## Основные ограничения

У каждого зрителя может быть только один живой усыновлённый герой. Повторно использовать команду можно после смерти или выхода предыдущего героя в отставку, если это допускают настройки стримера.

Стример может разрешить команду только платным подписчикам или установить минимальный срок подписки. При невыполнении этих условий усыновление отменяется.

Некоторые сочетания настроек несовместимы. Новый герой не может одновременно создаваться с выбором по имени, клану или фракции. Выбор культуры для нового героя поддерживается.

## Усыновление без аргументов

```text
!Усыновить
```

В стандартной конфигурации команда создаёт нового странника, размещает его в случайной таверне и присваивает ему имя зрителя.

Если стример отключил создание нового героя, команда без аргументов выбирает случайного доступного персонажа с учётом разрешённых типов героев.

## Режимы выбора героя

Аргумент команды зависит от настроенного стримером режима. Одновременно используется только один режим выбора.

### По культуре

```text
!Усыновить Империя
```

Достаточно ввести начало локализованного названия культуры. Регистр букв не учитывается.

Просмотр доступных культур:

```text
!Усыновить список
!Усыновить а
```

Для аргументов списка одновременно работают русские и английские варианты: `список` и `list`, `а` и `a`. Регистр букв не учитывается.

При создании нового героя выбранная культура определяет шаблон странника. При усыновлении существующего персонажа команда ищет доступного героя этой культуры.

### По фракции

```text
!Усыновить Вландия
```

Достаточно ввести начало локализованного названия фракции. Регистр букв не учитывается.

Просмотр доступных фракций:

```text
!Усыновить список
!Усыновить а
```

Этот режим применяется только к существующим героям. Не нанятые странники не состоят во фракции и поэтому не подходят под такой фильтр.

### По имени

```text
!Усыновить Каладог
```

Укажите полное локализованное имя героя. Регистр букв не учитывается. Если герой с таким именем не найден или недоступен по остальным условиям, команда завершится ошибкой.

### По клану

```text
!Усыновить Бану Сарран
```

Укажите полное локализованное название клана. Регистр букв не учитывается. Из подходящих доступных героев этого клана выбирается случайный персонаж.

### Случайный выбор

```text
!Усыновить
```

Если режим текстового выбора отключён и стример использует существующих персонажей, команда случайно выбирает героя, удовлетворяющего всем разрешённым фильтрам.

## Какие герои могут быть выбраны

При усыновлении существующего персонажа стример отдельно разрешает или запрещает:

- знатных героев;
- странников;
- лидеров отрядов;
- героев малых фракций;
- компаньонов игрока.

Герои мятежных кланов исключаются всегда: такой клан может быть удалён игрой после провала восстания.

Фильтр по культуре, фракции, имени или клану применяется вместе с этими ограничениями. Если подходящего доступного героя нет, команда сообщает об ошибке и никого не усыновляет.

## Создание и начальные параметры

Для нового или выбранного героя стример может задать:

- начальное золото;
- изменение возраста и диапазон случайного возраста;
- начальные навыки и диапазон их уровней;
- уровень начального снаряжения;
- начальный класс героя;
- показ внутриигрового уведомления об усыновлении.

Если список начальных навыков пуст, сохраняются исходные навыки персонажа. Если уровень снаряжения не задан, герой сохраняет существующее снаряжение.

При указанном классе начальное снаряжение подбирается с учётом этого класса. Конкретные предметы и значения навыков зависят от настроек стримера и доступного игрового содержимого.

## Наследство

Если предыдущий герой зрителя погиб или вышел в отставку, новый персонаж может получить часть вложенного имущества.

Стример настраивает:

- долю золота, потраченного на снаряжение и свиту, которая возвращается новому герою;
- максимальное количество наследуемых пользовательских предметов.

Значение доли задаётся от 0 до 1. Например, `0.25` означает наследование 25% учитываемых расходов.

Наследство добавляется после назначения начального золота. В итоговом сообщении команда перечисляет полученное золото и пользовательские предметы, если наследовать было что-либо.

## Настройки стримера

Стример может настроить:

- создание нового героя или выбор существующего;
- режим выбора: без аргумента, культура, фракция, имя или клан;
- разрешённые типы существующих героев;
- доступ только подписчикам;
- минимальное количество месяцев подписки;
- начальное золото, возраст, навыки, снаряжение и класс;
- долю наследства и лимит наследуемых пользовательских предметов;
- внутриигровое уведомление об успешном усыновлении;
- доступность команды в Twitch, оверлее и расширении.

Если включён текстовый режим выбора, для награды Twitch также должен быть включён пользовательский ввод. Иначе зритель не сможет передать требуемую культуру, фракцию, имя или клан.

## Краткий список команд

| Действие | Команда |
|---|---|
| Создать или выбрать случайного героя | `!Усыновить` |
| Выбрать по культуре | `!Усыновить Культура` |
| Показать культуры | `!Усыновить список` |
| Выбрать по фракции | `!Усыновить Фракция` |
| Показать фракции | `!Усыновить список` |
| Выбрать по имени | `!Усыновить ИмяГероя` |
| Выбрать по клану | `!Усыновить НазваниеКлана` |
