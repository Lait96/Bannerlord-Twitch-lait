# Удаление особого предмета

{% include doc-toc.html %}

Команда позволяет зрителю безвозвратно удалить один из особых предметов своего усыновлённого героя.

В примерах используется русский синоним `!выбросить`, доступный по умолчанию. Стример может изменить имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

## Основные ограничения

Для использования команды зрителю нужен усыновлённый герой с особым предметом. Удалить можно только предмет из собственного списка героя.

Удаление выполняется сразу и не требует подтверждения. Предмет исчезает безвозвратно, а освободившиеся ячейки снаряжения система при возможности заполняет обычной экипировкой героя.

## Просмотр особых предметов

Индекс нужного предмета можно посмотреть командой списка особых предметов:

```text
!customitems
```

Индексы начинаются с `1`. В команде удаления можно указать индекс с символом `#` или без него: `3` и `#3` обозначают один и тот же предмет.

## Удаление предмета

```text
!выбросить Индекс
```

Пример:

```text
!выбросить 3
```

Команда удаляет особый предмет с индексом `3` из списка героя.

У команды нет подкоманд. Она принимает один обязательный аргумент:

| Аргумент | Назначение |
|---|---|
| `Индекс` | Номер особого предмета в списке героя |

Если список пуст, индекс не является целым положительным числом или предмета с таким индексом нет, команда ничего не удалит и сообщит об ошибке.

## Настройки стримера

У команды нет отдельных игровых настроек. Стример может изменить её имя и синонимы, включить или отключить команду, скрыть её из справки и выбрать каналы, в которые отправляются ответы.

## Краткий список команд

| Действие | Команда |
|---|---|
| Удалить предмет | `!выбросить Индекс` |
