# Управление отрядом

{% include doc-toc.html %}

Команда позволяет зрителю управлять собственным отрядом, свободными отрядами клана и армиями.

В примерах используется стандартный русский синоним `!отряд`. Английская команда `!party` продолжает работать. Английские и русские названия подкоманд взаимозаменяемы.

Доступность действий, цены, радиусы и сроки приказов задаются стримером.

## Основные команды

| Действие | Команда |
|---|---|
| Показать состояние | `!отряд` |
| Создать отряд | `!отряд создать` |
| Стать губернатором | `!отряд управлять Название` |
| Показать статистику | `!отряд стат` |
| Распустить отряд | `!отряд распустить [Номер\|все]` |
| Вложить золото в тренировку | `!отряд тренировать Сумма` |
| Показать состояние тренировки | `!отряд тренировать статус` |
| Отменить тренировку | `!отряд тренировать отменить` |
| Снять действующий приказ | `!отряд освободить [все]` |

## Тренировка войск

Команда `!отряд тренировать Сумма` переводит указанное золото героя в фонд тренировки войск. Добавленные позже средства суммируются с остатком фонда.

Один раз в игровые сутки система пытается улучшить войска отряда героя и оплачивает фактическую стоимость улучшений из фонда. Дневные расходы ограничены глобальной настройкой стримера. Тренировка приостанавливается без расхода золота, если герой не возглавляет отряд, участвует в сражении или его отряд распускается.

Если стример установил максимальный уровень войск, сначала до него тренируется собственный отряд героя. После этого средства направляются в случайный свободный отряд того же клана, где ещё остались войска ниже заданного уровня. Когда подходящих улучшений нет, остаток сохраняется в фонде.

- `!отряд тренировать статус` показывает остаток фонда, максимальный дневной расход, примерное число дней и установленный предел уровня;
- `!отряд тренировать отменить` прекращает тренировку и возвращает герою весь неизрасходованный остаток.

Английские варианты `!party train`, `status` и `cancel` также продолжают работать.

## Приказы отрядам клана

К приказу можно добавить `все`, чтобы применить его ко всем свободным отрядам клана. Отряды, состоящие в армиях или участвующие в бою, исключаются.

| Действие | Команда |
|---|---|
| Осадить укрепление | `!отряд осада Поселение [все]` |
| Защищать поселение | `!отряд защищать Поселение [все]` |
| Патрулировать поселение | `!отряд патруль Поселение [все]` |
| Совершить набег | `!отряд набег Деревня [все]` |
| Войти в гарнизон | `!отряд гарнизон Укрепление [все]` |

## Управление армией

Армейские действия начинаются с `!отряд армия`.

| Действие | Команда |
|---|---|
| Показать состояние армии | `!отряд армия статус` |
| Создать армию | `!отряд армия создать` |
| Показать доступные армии | `!отряд армия список` |
| Присоединиться к армии | `!отряд армия присоединиться Номер` |
| Покинуть чужую армию | `!отряд армия покинуть` |
| Распустить армию | `!отряд армия распустить` |
| Передать командование | `!отряд армия передать Герой` |
| Перехватить командование | `!отряд армия перехватить Герой` |
| Созвать ближайшие отряды | `!отряд армия созвать рядом` |
| Созвать все отряды | `!отряд армия созвать все` |
| Исключить слабые отряды | `!отряд армия исключить [Количество]` |
| Найти ближайшие угрозы | `!отряд армия угрозы` |
| Отдать приказ армии | `!отряд армия осада\|защищать\|патруль\|гарнизон Поселение` |
| Снять приказ армии | `!отряд армия освободить` |

Король также может создавать и распускать армии королевства по номеру, а при включённых настройках — разрешать или запрещать создание армий ИИ и BLT.

## Ограничения

- Для команды нужен усыновлённый герой, состоящий в клане.
- Управление недоступно во время активной миссии.
- Большинство действий нельзя выполнять в плену или во время боя.
- Для приказов армии герой должен возглавлять её; отдельные действия доступны только лидеру клана или королю.
- Наёмники не могут создавать и созывать армии, но присоединение к армиям не требует у них влияния.
