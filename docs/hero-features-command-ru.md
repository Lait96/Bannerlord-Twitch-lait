# Особенности героя

{% include doc-toc.html %}

Команда позволяет зрителю менять пол, внешность, расу и культуру усыновлённого героя, а также заключать брак с существующим персонажем или созданным супругом.

В примерах используется русский синоним `!Герой`, доступный по умолчанию. Стример может изменить основное имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

Доступность отдельных действий, их стоимость и ограничения зависят от настроек стримера.

## Общие ограничения

Для использования команды у зрителя должен быть усыновлённый герой.

Изменение особенностей героя недоступно:

- во время активной миссии, включая сражение или турнир;
- пока герой находится в плену.

У команды нет отдельного режима просмотра. После русского имени команды всегда указывается одна из подкоманд: `пол`, `внешность`, `брак`, `раса` или `культура`.

Английские варианты подкоманд и фиксированных аргументов также работают независимо от выбранного языка мода. Например, команды `!Герой пол мужчина` и `!Герой gender male` выполняют одно действие.

## Смена пола

Сменить пол на мужской:

```text
!Герой пол мужчина
```

Сменить пол на женский:

```text
!Герой пол женщина
```

Подкоманда списывает с героя настроенную сумму BLT-золота. Если у героя недостаточно средств или выбран его текущий пол, действие не выполняется.

По умолчанию менять пол можно только героям, которые были созданы системой усыновления, а не выбраны среди существующих персонажей Bannerlord. Стример может снять это ограничение.

Беременная героиня не может сменить пол на мужской. Если супруг героя после смены оказывается того же пола, команда автоматически меняет пол супруга на противоположный.

## Изменение внешности

```text
!Герой внешность КОД_ВНЕШНОСТИ
```

После подкоманды передаётся полная строка `BodyProperties` формата Bannerlord. Она должна соответствовать версии 4 и содержать поля `age`, `weight`, `build` и `key`, например:

```text
!Герой внешность <BodyProperties version="4" age="30" weight="0.5" build="0.5" key="DEADBEEF" />
```

Значения `weight` и `build` должны быть больше нуля и не больше `1`, а `key` должен состоять из шестнадцатеричных символов.

Возраст из переданной строки не применяется: команда заменяет его текущим возрастом героя. Пол и раса героя сохраняются.

Команда изменяет внешность без списания BLT-золота, но стример может полностью отключить эту возможность.

## Брак

Действие доступно только герою-дворянину, который состоит в клане и ещё не имеет супруга. После успешного брака с героя списывается настроенная стоимость.

Режим работы зависит от настройки **«Только создавать супруга»**.

### Создать супруга

В стандартной конфигурации команда создаёт нового супруга выбранной культуры:

```text
!Герой брак Империя
```

Название культуры обязательно. Поиск не учитывает регистр и допускает совпадение по части локализованного названия культуры.

Новый персонаж:

- создаётся на основе доступного шаблона странника выбранной культуры;
- становится дворянином и вступает в клан героя;
- получает противоположный пол;
- получает возраст, близкий к возрасту героя, но не ниже возраста совершеннолетия;
- размещается в подходящем городе.

Если для выбранной культуры нет подходящего шаблона, используется доступный шаблон другой культуры, после чего персонажу назначается выбранная культура.

### Выбрать существующего супруга

Если создание супруга отключено, команда выбирает подходящего свободного дворянина:

```text
!Герой брак Вландия
```

Аргумент необязателен. Без него супруг выбирается случайно. Если указана культура, поиск ограничивается персонажами этой культуры; при наличии королевства предпочтение отдаётся дворянам из того же королевства.

Стример может дополнительно разрешить выбор по началу имени героя или названию клана:

```text
!Герой брак dey
```

Сначала команда ищет совпадение по имени или клану. Если совпадений нет, аргумент рассматривается как начало названия культуры.

Подходящий существующий супруг должен быть совершеннолетним свободным дворянином противоположного пола. Персонаж игрока и его компаньоны в список не входят. После брака супруг вступает в клан героя, а его возраст приводится к диапазону около возраста героя.

Если подходящего персонажа найти не удалось и поиск выполнялся не по имени или клану, команда создаёт запасного супруга культуры героя.

## Смена расы

```text
!Герой раса 0
```

Аргумент — числовой идентификатор расы. Команда принимает доступные идентификаторы от `0` до `31`, для которых в игре существует базовый тип существа и которые не запрещены стримером.

При неверном значении команда выводит список доступных идентификаторов и их внутренних названий.

После смены расы телосложение героя сбрасывается к минимальным свойствам персонажа для выбранной расы. Пол героя сохраняется. В стандартной конфигурации подкоманда отключена.

## Смена культуры

```text
!Герой культура Вландия
```

После подкоманды указывается полное локализованное название разрешённой культуры. Регистр букв не учитывается.

Команда меняет культуру героя и его клана. Культуры, внутренние идентификаторы которых добавлены стримером в список запрещённых, выбрать нельзя.

Смена культуры не требует BLT-золота и в стандартной конфигурации включена.

## Настройки стримера

| Настройка | Назначение | Стандартное значение |
|---|---|---:|
| Смена пола | Разрешает подкоманду `пол` | Включено |
| Стоимость смены пола | Количество BLT-золота за смену пола | `10000` |
| Только созданные герои | Запрещает смену пола существующим героям Bannerlord | Включено |
| Изменение внешности | Разрешает подкоманду `внешность` | Включено |
| Брак | Разрешает подкоманду `брак` | Включено |
| Стоимость брака | Количество BLT-золота за успешный брак | `50000` |
| Только создавать супруга | Всегда создаёт нового супруга выбранной культуры | Включено |
| Выбор клана или имени | Разрешает искать существующего супруга по клану или имени | Отключено |
| Смена расы | Разрешает подкоманду `раса` | Отключено |
| Запрещённые расы | Список недоступных числовых идентификаторов через запятую | Пусто |
| Смена культуры | Разрешает подкоманду `культура` | Включено |
| Запрещённые культуры | Список недоступных внутренних идентификаторов через запятую | Пусто |

Стример также может отключить саму команду, изменить основное имя `hero` и список синонимов, включая `Герой`, ограничить использование модераторами, скрыть команду из справки и выбрать каналы для вывода ответа.
