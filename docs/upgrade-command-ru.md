# Управление улучшениями

{% include doc-toc.html %}

Команда улучшений позволяет приобретать, просматривать и удалять улучшения владений, клана и королевства. Стоимость, требования и эффекты каждого улучшения задаются стримером.

В примерах используется русский синоним `!Апгрейд`, доступный по умолчанию. Стример может изменить имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

Русские подкоманды можно заменять английскими вариантами: например, `владение` и `fief`, `список` и `list`, `все` и `all` работают одинаково. Регистр букв не учитывается.

## Общие ограничения

Для использования команды у зрителя должен быть усыновлённый герой. Система улучшений должна быть включена стримером.

Команда недоступна во время активной миссии, включая сражение или турнир.

Для покупки и удаления улучшений действуют права владельца, лидера клана и правителя королевства. Некоторые улучшения дополнительно требуют:

- ранее приобретённые улучшения;
- прибрежное поселение;
- действующую столицу клана;
- достаточное количество золота;
- достаточное количество влияния для улучшений королевства.

## Просмотр доступных улучшений

```text
!Апгрейд список
!Апгрейд список владение
!Апгрейд список клан
!Апгрейд список королевство
```

Без дополнительного аргумента выводятся все настроенные улучшения. Указание типа ограничивает список одной категорией.

Для каждого улучшения показываются ID, название, стоимость и описание. ID используется во всех командах покупки и удаления. Стример может отключить просмотр списка.

## Просмотр приобретённых улучшений

```text
!Апгрейд сведения владение Название поселения
!Апгрейд сведения клан [Название клана]
!Апгрейд сведения королевство Название королевства
```

Команда показывает приобретённые улучшения выбранного владения, клана или королевства. Для клана название можно не указывать — тогда используется клан героя.

Если улучшения образуют последовательность уровней, в списке отображается только самый высокий приобретённый уровень каждой последовательности.

## Покупка улучшения владения

```text
!Апгрейд владение Название поселения ID
```

Покупает указанное улучшение для города или замка. Обычно герой должен принадлежать клану-владельцу и быть его лидером. Стример может разрешить правителю королевства улучшать поселения других кланов своего королевства.

Улучшение только для побережья можно приобрести лишь в поселении с портом. Улучшение только для столицы требует, чтобы выбранное поселение было действующей столицей клана.

Если вместо города указана принадлежащая ему деревня, команда также пытается найти связанный замок по его локализованному или английскому названию.

## Покупка улучшения клана

```text
!Апгрейд клан ID
```

Покупает улучшение для текущего клана героя. По умолчанию это может делать только лидер клана, но стример может разрешить покупку любому члену клана.

## Покупка улучшения королевства

```text
!Апгрейд королевство ID
```

Покупает улучшение для королевства героя. Команда доступна только правителю. Помимо золота, улучшение может требовать влияние клана.

## Автоматическая покупка требований

Перед любой командой покупки или после неё можно добавить режим `авто` либо `пакет`:

```text
!Апгрейд авто клан clan_renown2
!Апгрейд клан clan_renown2 пакет
```

Оба режима работают одинаково. Если целевому улучшению не хватает предыдущих уровней или других обязательных улучшений, команда последовательно приобретает их, а затем пытается купить выбранное улучшение.

Без `авто` или `пакет` покупка останавливается и выводит список недостающих требований. Уже приобретённые требования повторно не оплачиваются. Если золото или влияние закончилось в середине цепочки, успешно купленные улучшения сохраняются, а команда сообщает причину остановки.

## Массовая покупка

### Все категории

```text
!Апгрейд все
!Апгрейд авто все
```

Команда пытается приобрести доступные улучшения владений, клана и королевства. Категории, для которых у героя нет необходимых прав или подходящей цели, пропускаются с пояснением.

### Все улучшения владений

```text
!Апгрейд владение все
!Апгрейд авто владение все
```

Покупает доступные улучшения для подходящих поселений клана. В зависимости от прав и настроек в выборку могут входить владения вассалов или другие поселения королевства.

### Все улучшения клана или королевства

```text
!Апгрейд клан все
!Апгрейд королевство все
```

Команды приобретают доступные улучшения соответствующей категории. Для улучшений королевства герой должен быть правителем.

### Одно улучшение для владений королевства

```text
!Апгрейд владение всекоролевство ID
```

Применяет выбранное улучшение ко всем подходящим городам и замкам королевства. Для каждого поселения отдельно проверяются уже приобретённые улучшения, требования, столичный статус и доступные средства.

Доступ к этому режиму определяется правами правителя и настройками стримера. Аргументы `все` и `всекоролевство` нельзя использовать одновременно.

## Удаление улучшений

```text
!Апгрейд удалить владение Название поселения ID
!Апгрейд удалить клан ID
!Апгрейд удалить королевство ID
```

Удаление доступно только для улучшений, которые стример отметил как удаляемые.

Для владения действуют те же права владельца и правителя, что и при покупке. Улучшения клана по умолчанию удаляет лидер клана, а улучшения королевства — только правитель.

Удаление не возвращает потраченное золото или влияние.

## Настройки стримера

Стример может настроить:

- включение всей системы улучшений;
- доступность команды `список`;
- накопление создаваемых улучшениями бойцов, когда военные отряды и гарнизоны заполнены;
- право правителя покупать улучшения для владений других кланов королевства;
- право любого члена клана покупать и удалять улучшения клана;
- применение улучшений «только для лордов» к независимым кланам, владеющим поселениями;
- применение улучшений «только для наёмников» к независимым кланам, владеющим поселениями.

Сами списки улучшений настраиваются отдельно для владений, кланов и королевств. Для каждого улучшения могут задаваться ID, название, описание, стоимость, уровень, требования, возможность удаления, ограничения и игровые эффекты.
