# Улучшение снаряжения

{% include doc-toc.html %}

Команда улучшает снаряжение усыновлённого героя до следующего уровня. Система сама подбирает оружие, броню, коня и упряжь с учётом класса героя, его навыков и доступных предметов.

В примерах используется русский синоним `!Снаряга`, доступный по умолчанию. Стример может изменить имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

## Основные ограничения

Для использования команды зрителю нужен усыновлённый герой с назначенным классом и достаточным количеством золота.

Команда недоступна:

- во время миссии, в том числе сражения;
- после достижения максимального, шестого уровня снаряжения;
- компаньонам игрока, если стример запретил им улучшать снаряжение.

Золото списывается после успешного подбора снаряжения. Стоимость зависит от уровня, который герой получает в результате улучшения.

## Улучшение снаряжения

```text
!Снаряга
```

Команда без аргументов повышает текущий уровень снаряжения героя на один и подбирает подходящие предметы без ограничения по культуре.

Номер желаемого уровня указывать не нужно: команда всегда определяет следующий уровень автоматически. Текстовый аргумент используется только как фильтр культуры предметов.

## Фильтр по культуре

```text
!Снаряга Название культуры
```

Пример:

```text
!Снаряга Вландия
```

Название культуры можно ввести полностью или частично. Поиск выполняется без учёта регистра по локализованным названиям культур из игры. Если текст подходит нескольким культурам, используется первое найденное совпадение.

Фильтр влияет на подбор новых предметов, но не гарантирует, что всё снаряжение будет принадлежать выбранной культуре. Если подходящего предмета не найдётся, система сначала попробует более низкий уровень, затем разрешит повторяющиеся предметы, а в последнюю очередь повторит поиск без фильтра культуры.

Если введённый текст не совпадает ни с одной культурой, команда продолжит работу без культурного фильтра.

### Предметы без культуры

Для предметов, у которых культура не указана, доступны русский и английский варианты аргумента:

```text
!Снаряга без культуры
!Снаряга null
```

Оба варианта выполняют одно и то же действие. Регистр букв не учитывается.

У команды нет подкоманд. Она принимает один необязательный аргумент:

| Аргумент | Назначение |
|---|---|
| `Название культуры` | Предпочитать предметы выбранной культуры |
| `без культуры` или `null` | Предпочитать предметы без указанной культуры |

## Как подбирается снаряжение

При обычном улучшении система сохраняет особые предметы героя, а также обычные предметы текущего или более высокого уровня. Предметы из списка запрещённых стримером не используются.

Оружие подбирается под слоты и типы оружия, заданные классом героя. Для дальнобойного оружия добавляются подходящие боеприпасы. Броня заполняет предусмотренные слоты, а конному классу подбираются конь и совместимая упряжь.

По возможности команда избегает одинаковых предметов. Если уникального набора собрать нельзя, повторения разрешаются, чтобы не оставить подходящий слот пустым. Когда новая броня для слота не найдена, прежний предмет сохраняется.

## Режим переснаряжения

Стример может включить настройку «Переснаряжать вместо улучшения». В этом режиме команда не повышает уровень, а заново подбирает снаряжение на текущем уровне.

Предметы более высокого уровня и особые предметы по-прежнему сохраняются. Обычные предметы текущего уровня могут быть заменены. Фильтр культуры и аргумент `без культуры` работают так же, как при обычном улучшении.

В стандартной конфигурации режим переснаряжения вынесен в отдельную скрытую команду `reequip`, а русский синоним `!Снаряга` относится к обычному повышению уровня.

## Настройки стримера

### Улучшение компаньонов

Определяет, могут ли усыновлённые герои, которые стали компаньонами игрока, менять снаряжение этой командой. В стандартной конфигурации улучшение компаньонов разрешено.

### Стоимость уровней

Для каждого из шести уровней задаётся отдельная цена. Команда использует стоимость нового уровня, а не текущего.

В стандартной конфигурации команды `equip` установлены следующие цены:

| Уровень | Стоимость |
|---:|---:|
| 1 | `25 000` |
| 2 | `50 000` |
| 3 | `100 000` |
| 4 | `200 000` |
| 5 | `400 000` |
| 6 | `1 000 000` |

### Переснаряжение вместо улучшения

Переключает обработчик с повышения уровня на повторный подбор предметов текущего уровня. Для отдельной стандартной команды `reequip` используются собственные цены.

Стример также может включить или отключить команду, изменить основное имя `equip` и список синонимов, включая `Снаряга`, ограничить использование модераторами, скрыть команду из справки и выбрать каналы для вывода ответа.

В стандартной конфигурации ответы команды выводятся в оверлей.

## Краткий список команд

| Действие | Команда |
|---|---|
| Улучшить снаряжение | `!Снаряга` |
| Выбрать культуру | `!Снаряга Название культуры` |
| Выбрать предметы без культуры | `!Снаряга без культуры` |
