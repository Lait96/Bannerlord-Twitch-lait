# Улучшение атрибутов

{% include doc-toc.html %}

Команда атрибутов позволяет зрителю купить очки одного из шести основных атрибутов для своего усыновлённого героя.

В примерах используется русский синоним `!атрибут`, доступный по умолчанию. Стример может изменить имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

## Основные ограничения

Для использования команды у зрителя должен быть усыновлённый герой и достаточно золота для оплаты установленной стримером стоимости.

Значение каждого атрибута ограничено 10 очками. Если выбранный атрибут уже достиг максимума, команда завершится ошибкой. Если все атрибуты героя равны 10, улучшить героя этой командой невозможно.

Золото списывается только после успешного улучшения.

## Выбор атрибута

```text
!атрибут Название атрибута
```

У команды нет отдельных подкоманд. По умолчанию единственный аргумент — локализованное название атрибута или его часть. Регистр букв не учитывается.

Доступны шесть атрибутов:

| Атрибут | Пример                  |
|---|-------------------------|
| Энергичность | `!атрибут энергия`      |
| Контроль | `!атрибут контроль`     |
| Выносливость | `!атрибут выносливость` |
| Хитрость | `!атрибут хитрость`     |
| Обаяние | `!атрибут обаяние`      |
| Интеллект | `!атрибут интеллект`    |

Полное название вводить необязательно. Например:

```text
!атрибут вын
!атрибут хит
!атрибут инт
```

Сокращение должно позволять выбрать нужный атрибут. Если введённая часть совпадает с несколькими названиями, команда использует первое подходящее значение из внутреннего списка атрибутов. Поэтому лучше вводить достаточно различимую часть названия.

Если название не указано или совпадение не найдено, атрибут не изменяется и золото не списывается.

## Случайный атрибут

Стример может включить случайный выбор. В этом режиме команда используется без аргумента:

```text
!атрибут
```

Система случайно выбирает один из атрибутов, которые ещё не достигли 10 очков. Переданный текстовый аргумент в этом режиме не влияет на выбор.

Атрибуты максимального уровня не участвуют в случайном выборе.

## Количество очков

За одно успешное использование команда добавляет случайное количество очков из диапазона, заданного стримером.

Фактическое улучшение не может превысить предел в 10 очков. Например, если у героя 9 очков выбранного атрибута, а команда должна добавить 3, герой получит только 1 очко.

Стоимость команды при таком ограничении не пересчитывается: после успешного улучшения списывается полная настроенная сумма.

## Настройки стримера

Стример может настроить:

- **минимальное количество очков** — нижнюю границу случайного улучшения;
- **максимальное количество очков** — верхнюю границу случайного улучшения;
- **стоимость в золоте** — сумму, которая списывается с героя после успеха;
- **случайный выбор** — требуется ли название атрибута или система выбирает его сама;
- имя команды и её синонимы;
- доступность команды, права модератора и каналы вывода ответа.

В стандартной конфигурации команда добавляет 1 очко, стоит 250 000 золота и требует указать атрибут.
