# Журнал кампании

{% include doc-toc.html %}

Команда показывает последние события кампании, связанные с усыновлённым героем зрителя, выбранным кланом, королевством или владением.

В примерах используется русский синоним `!журнал`, доступный по умолчанию. Стример может изменить имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

Русские и английские названия подкоманд работают одновременно и без учёта регистра. Например, `герой` и `hero` открывают один и тот же журнал.

## Общие ограничения

Для использования команды у зрителя должен быть усыновлённый герой. Это требование действует для всех режимов, в том числе при просмотре чужого клана, королевства или владения.

Журнал содержит только события, которые система отслеживала во время текущей кампании. Если для выбранного объекта ещё нет записей, команда сообщит об этом. После достижения настроенного лимита самые старые записи удаляются, поэтому журнал не является полной историей прохождения.

В стандартной конфигурации команда отключена. Стример должен включить её, прежде чем зрители смогут пользоваться журналом.

## События героя

```text
!журнал герой
```

Показывает журнал усыновлённого героя зрителя. Дополнительный аргумент не требуется: команда всегда использует героя автора сообщения.

В журнал могут попадать результаты сражений, пленение и освобождение героя, создание армии и присоединение отряда героя к армии.

## События клана

```text
!журнал клан
!журнал клан дей Мерок
```

Без аргумента команда показывает журнал текущего клана усыновлённого героя. Если герой не состоит в клане, необходимо указать название явно.

Название можно ввести целиком или частично. Сначала команда ищет полное совпадение без учёта регистра, затем первое название, содержащее введённый текст. Чтобы избежать случайного совпадения, используйте достаточно различимую часть названия.

В журнал клана могут попадать рождение, брак и смерть героев, переход клана между королевствами, создание отрядов и достижение героем совершеннолетия.

## События королевства

```text
!журнал королевство
!журнал королевство Вландия
```

Без аргумента команда использует королевство текущего клана усыновлённого героя. Если определить его невозможно, необходимо указать название королевства.

Название можно ввести целиком или частично. Поиск выполняется без учёта регистра; при частичном поиске используется первое найденное совпадение.

В журнал королевства могут попадать объявления войн и заключение мира, создание и расторжение союзов, торговые соглашения и переход владений между королевствами.

## События владения

```text
!журнал владение Правенд
```

Показывает журнал указанного города или замка. Название владения является обязательным аргументом.

Сначала команда ищет полное совпадение без учёта регистра, затем первое владение, название которого содержит введённый текст. В журнал могут попадать смена владельца и начало осады.

## Настройки стримера

Стример может задать максимальное количество записей отдельно для каждого вида журнала:

| Настройка | Назначение | Стандартное значение |
|---|---|---:|
| Максимум записей героя | Лимит событий для одного героя | `10` |
| Максимум записей клана | Лимит событий для одного клана | `10` |
| Максимум записей королевства | Лимит событий для одного королевства | `10` |
| Максимум записей владения | Лимит событий для одного владения | `10` |

После заполнения журнала новая запись заменяет самую старую. Значение `0` отключает сбор событий соответствующего вида.

Также стример может включить или отключить команду, изменить основное имя `logs` и список синонимов, включая `журнал`, разрешить использование только модераторам, скрыть команду из справки и выбрать каналы для вывода ответа.

В стандартной конфигурации ответы отправляются в Twitch.
