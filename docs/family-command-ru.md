# Управление семьёй

{% include doc-toc.html %}

Команда семьи позволяет зрителю просматривать родственников героя, управлять супругом и детьми, менять их внешность и имена, инициировать рождение ребёнка и заключать браки между детьми зрителей.

В примерах используется русский синоним `!Семья`, доступный по умолчанию. Стример может изменить имя команды или её синонимы. В этом случае используйте вариант, указанный в списке команд канала.

Доступность отдельных действий и лимит живых детей зависят от настроек стримера.

## Общие ограничения

Команда недоступна:

- если у зрителя нет усыновлённого героя;
- во время активной миссии.

Максимальное количество живых детей в клане для команды рождения задаётся стримером. Значение по умолчанию — 3.

Имена родственников указываются одним словом. Поиск не учитывает регистр и допускает совпадение по части имени.

## Обзор семьи

```text
!Семья
```

Команда показывает количество живых супругов, детей, внуков, правнуков, родителей, братьев и сестёр.

## Супруг

### Показать сведения

```text
!Семья супруг
```

Команда показывает имя, возраст, пол, беременность и лучший навык текущего супруга. Если текущего супруга нет, команда перечисляет бывших супругов.

### Переименовать

```text
!Семья супруг переименовать НовоеИмя
```

### Изменить внешность

```text
!Семья супруг внешность КОД_ВНЕШНОСТИ
```

### Показать навыки

```text
!Семья супруг навыки
```

### Инициировать рождение ребёнка

```text
!Семья супруг ребёнок
```

Команда делает героя или его супругу беременной, если персонаж ещё не беременен и не достигнут настроенный лимит живых детей в клане.

## Дети и внуки

### Показать список детей

```text
!Семья дети
```

Для каждого ребёнка выводятся имя, возраст, пол, семейное положение, состояние и количество детей.

### Показать сведения о ребёнке

```text
!Семья ИмяРебёнка
```

Если найдено несколько детей с одинаковым именем, команда покажет нумерованный список. После этого добавьте номер к имени, например `Caladog1`.

### Показать сведения о внуке или супруге ребёнка

```text
!Семья ИмяРебёнка ИмяВнука
```

### Переименовать ребёнка

```text
!Семья ИмяРебёнка переименовать НовоеИмя
```

### Изменить внешность ребёнка

```text
!Семья ИмяРебёнка внешность КОД_ВНЕШНОСТИ
```

### Показать навыки ребёнка

```text
!Семья ИмяРебёнка навыки
```

## Родители

```text
!Семья родители
```

Команда показывает имена отца и матери героя. Умершие родители отмечаются символом 💀.

## Браки между детьми зрителей

```text
!Семья ИмяСвоегоРебёнка поженить ИмяЗрителя ИмяЕгоРебёнка
```

Первый зритель отправляет предложение и тем самым предлагает своего ребёнка. Второй зритель повторяет зеркальную команду для подтверждения. Оба героя должны быть совершеннолетними, не состоять в браке, не быть усыновлёнными героями BLT и не возглавлять кланы.

Отклонение предложения:

```text
!Семья ИмяСвоегоРебёнка поженить ИмяЗрителя отклонить
```

## Настройки стримера

### Максимальное количество детей

Определяет максимальное количество живых детей в клане, при котором команда `супруг ребёнок` может инициировать беременность.

По умолчанию разрешено не более трёх живых детей. Стример может изменить этот лимит.

Настройка влияет только на рождение ребёнка через команду семьи. Просмотр родственников, изменение внешности и имён, просмотр навыков и заключение браков остаются доступными.
