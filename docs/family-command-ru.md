# Управление семьёй

{% include doc-toc.html %}

Команда позволяет просматривать семью усыновлённого героя, управлять супругом и детьми, узнавать сведения о внуках, менять внешность и имена родственников, инициировать рождение ребёнка и заключать браки между детьми зрителей.

В примерах используется стандартный русский синоним `!семья`. Английская команда `!family`, а также английские названия подкоманд продолжают работать.

## Общие ограничения

- Для команды нужен усыновлённый герой.
- Команда недоступна во время активной миссии.
- Максимальное количество живых детей в клане для команды рождения задаётся стримером; значение по умолчанию — 3.
- Имена родственников указываются одним словом. Поиск не учитывает регистр и допускает совпадение по части имени.

## Обзор семьи

```text
!семья
```

Показывает количество живых супругов, детей, внуков, правнуков, родителей, братьев и сестёр.

## Супруг

### Показать сведения

```text
!семья супруг
```

Показывает имя, возраст, пол, беременность и лучший навык текущего супруга. Если текущего супруга нет, команда перечисляет бывших супругов.

### Переименовать

```text
!семья супруг переименовать НовоеИмя
```

### Изменить внешность

```text
!семья супруг внешность КОД_ВНЕШНОСТИ
```

### Показать навыки

```text
!семья супруг навыки
```

### Инициировать рождение ребёнка

```text
!семья супруг ребёнок
```

Команда делает героя или его супругу беременной, если персонаж ещё не беременен и не достигнут настроенный лимит живых детей в клане.

## Дети и внуки

### Показать список детей

```text
!семья дети
```

Для каждого ребёнка выводятся имя, возраст, пол, семейное положение, состояние и количество детей.

### Показать сведения о ребёнке

```text
!семья ИмяРебёнка
```

Если найдено несколько детей с одинаковым именем, команда покажет нумерованный список. После этого добавьте номер к имени, например `Caladog1`.

### Показать сведения о внуке или супруге ребёнка

```text
!семья ИмяРебёнка ИмяВнука
```

### Переименовать ребёнка

```text
!семья ИмяРебёнка переименовать НовоеИмя
```

### Изменить внешность ребёнка

```text
!семья ИмяРебёнка внешность КОД_ВНЕШНОСТИ
```

### Показать навыки ребёнка

```text
!семья ИмяРебёнка навыки
```

## Родители

```text
!семья родители
```

Показывает имена отца и матери героя. Умершие родители отмечаются символом 💀.

## Браки между детьми зрителей

```text
!семья ИмяСвоегоРебёнка поженить ИмяЗрителя ИмяЕгоРебёнка
```

Первый зритель отправляет предложение и тем самым предлагает своего ребёнка. Второй зритель повторяет зеркальную команду для подтверждения. Оба героя должны быть совершеннолетними, не состоять в браке, не быть усыновлёнными героями BLT и не возглавлять кланы.

Отклонение предложения:

```text
!семья ИмяСвоегоРебёнка поженить ИмяЗрителя отклонить
```

## Русские и английские подкоманды

| Действие | Русская подкоманда | Английская подкоманда |
|---|---|---|
| Супруг | `супруг` | `spouse` |
| Дети | `дети` | `children` |
| Родители | `родители` | `parents` |
| Внешность | `внешность` | `looks` |
| Переименовать | `переименовать` | `rename` |
| Рождение ребёнка | `ребёнок` | `baby` |
| Навыки | `навыки` | `skills` |
| Поженить | `поженить` | `marry` |
| Отклонить предложение | `отклонить` | `reject` |
